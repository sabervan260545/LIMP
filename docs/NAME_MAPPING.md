# Name mapping

| Paper-facing name | Historical/internal name | Meaning |
|---|---|---|
| LIMP | LIUP | Continuous laboratory method family; paper-facing name |
| LIMP-DI | LIUP-DI | Original discriminative inverse-design implementation |
| LIMP-AR | LIUP-AR | Production-oriented AMP-only autoregressive implementation |
| `limp-generator` | `liup-generator` | Public label versus frozen service ID |
| `limp_generator` | `liup_generator` | Public label versus backward-compatible Python package |

The mapping does not imply that LIMP-DI and LIMP-AR are the same model and does
not alter any checkpoint, sequence, hash or historical run identifier.
